# Flor de Lista — Um dia mais leve

O **Flor de Lista** é uma aplicação web para organizar tarefas pessoais com uma proposta visual delicada em rosa e branco. A ideia é transformar o planejamento da rotina em uma experiência simples, acolhedora e fácil de acompanhar.

## Ideia do projeto

Cada usuário possui um espaço próprio para anotar seus planos, definir prioridades e acompanhar pequenas conquistas. A aplicação incentiva a organização por etapas, permitindo visualizar tanto o que ainda precisa ser feito quanto o progresso já alcançado.

## Funcionalidades

- Cadastro e login por e-mail e senha.
- Criação, consulta, edição e exclusão de tarefas.
- Título, detalhes opcionais e três níveis de prioridade.
- Marcação de tarefas concluídas e possibilidade de reabri-las.
- Busca por texto e filtros de status.
- Contadores e indicador de progresso.
- Sincronização em tempo real e dados separados por usuário.
- Layout adaptado para computadores e celulares.

## Identidade visual

A interface combina fundo branco, diferentes tons de rosa, cantos arredondados e ilustrações florais. O painel lateral organiza o espaço, enquanto a lista apresenta as tarefas de forma clara. Os títulos usam uma fonte serifada para dar um toque de papelaria ao projeto.

## Tecnologias utilizadas

- **HTML:** estrutura das telas.
- **CSS:** aparência e layout responsivo.
- **JavaScript:** interações e gerenciamento das tarefas.
- **Firebase Authentication:** autenticação dos usuários.
- **Cloud Firestore:** armazenamento e atualização em tempo real, com regras de acesso por usuário.

## Objetivo acadêmico

Praticar o desenvolvimento de aplicações web com HTML, CSS e JavaScript puros, integrando autenticação e operações de criar, ler, atualizar e excluir dados (CRUD) aos serviços do Firebase.
